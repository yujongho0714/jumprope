계급 JSON 적용 (무조건 덮어쓰기)

JSON 파일에 적힌 계급을 수련생 명단에 그대로 적용해요. 지금 계급보다 낮아도 무조건 그 계급으로 맞춰요.
지원 형식: {"이름": 계급} · [{"name":"이름","level":계급}] · 이 앱의 전체 백업 파일(기록으로 계급 계산)

다른 파일 기록 가져오기

영문판 줄넘기 파일에서 "기록 내보내기"로 저장한 JSON 파일을 불러오면, 이 파일의 기록에 합쳐져요. (중복 기록은 자동으로 걸러져요)

계급 관리
누적 줄넘기 개수가 늘어날 때마다 1계급씩 올라가요. 1~10계급은 10개씩, 11~20계급은 20개씩, 21~30계급은 30개씩, 31~40계급은 40개씩... 이런 식으로 10단위 구간마다 필요한 개수가 늘어나요. 아래 버튼으로 1계급부터 순서대로 이미지를 여러 장 한번에 선택하면 선택한 순서대로 등록돼요. gif · webp · png · jpg 모두 사용할 수 있어요.
훈장 보관함 관리
수련생 한 명의 누적 줄넘기 개수가 300개 늘어날 때마다, 아래 훈장들 중 하나를 랜덤으로 1개 획득해요. 획득한 훈장은 수련생 명단에서 자유롭게 착용할 수 있고, 착용한 훈장은 게임 진행 중과 결과 화면에 표시돼요. gif · webp · png · jpg 모두 사용할 수 있어요.
